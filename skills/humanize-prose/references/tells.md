# The tells catalogue

What gives LLM writing away, grouped by the pass that removes it. A single
hit isn't proof; a cluster is. Hunt for clusters.

## Pass 1: vocabulary

Swap for the plain word, or delete when the word carries nothing.

| Tell | Plain replacement |
|---|---|
| delve, dive into, deep dive | look at, go through (or delete) |
| crucial, pivotal, vital, essential, paramount | important, or say why it matters |
| leverage, utilize, harness | use |
| robust, comprehensive, holistic | say what it covers, or delete |
| seamless, seamlessly | delete, or say what doesn't break |
| streamline, optimize (as filler) | speed up, simplify, cut |
| landscape, realm, ecosystem, tapestry, space | field, area, or delete |
| navigate (a problem), embark, journey | deal with, start |
| foster, empower, elevate, unlock | help, let, improve |
| facilitate | help, run |
| ensure | make sure, or delete |
| underscore, highlight (as verbs for "shows") | show |
| testament to | shows |
| meticulous, intricate, nuanced | careful, detailed, or delete |
| game-changer, cutting-edge, next-level | say what changed |
| moreover, furthermore, additionally | and, also, or a full stop |
| notably, importantly, interestingly | delete |
| ultimately, at the end of the day | delete |

## Pass 1: stock phrases

Delete outright; none of these carry meaning.

- "In today's fast-paced world / landscape"
- "It's worth noting that", "It's important to remember"
- "Let's dive in", "Let's break it down", "Let's explore"
- "Here's the thing:", "The reality is", "The truth is"
- "Great question", "I hope this helps", "Feel free to reach out"
- "Whether you're a X or a Y"
- "In summary", "In conclusion", "To sum up", "Overall" (as a closer)
- "When it comes to"
- "plays a key role in"

## Pass 1: structures

| Tell | Fix |
|---|---|
| Em dash or en dash mid-sentence | Full stop, comma, colon or parentheses |
| "It's not X, it's Y" / "not just X, but Y" | State Y |
| Triad: three adjectives, three benefits, three verbs | Keep the strongest one; keep a real list of three distinct items |
| Rhetorical question then answer ("Why does this matter? Because...") | State the answer |
| Colon reveal ("The result: faster builds.") as a habit | One per text at most |
| Closer that restates the opening | Delete it |
| Bold-lead bullets where prose would do | Prose |
| Emoji bullets, emoji section headers | Remove |
| Title Case Headings | Sentence case |

## Pass 2: rhythm

- Three or more consecutive sentences within about four words of each other in length.
- Every paragraph the same length (often three or four sentences).
- Consecutive sentences opening with the same word or shape ("This...", "This...").
- Every sentence a subject-verb-object statement; no fragments, no questions.
- Every list item the same length and grammar.

## Pass 3: fence-sitting

- "It depends", "there's no one-size-fits-all", "every team is different"
- "On the other hand", "That said", "However, it's also important to"
- "may", "might", "could potentially", "can help to" stacked on a claim the author believes
- "Some argue X, others argue Y" with no verdict
- A pros-and-cons list that never picks

Keep a caveat when it's true and the reader would get hurt without it: a known
limitation, a cost, a risk, a regulatory or compliance condition.

## Pass 4: written-not-spoken

- Formal transitions: moreover, furthermore, additionally, consequently, thus, hence
- No contractions anywhere ("it is", "do not", "we will")
- Setup before the point: background paragraph, then the ask in the last line
- Throat-clearing: "I wanted to reach out regarding", "I am writing to"
- Passive voice that hides who does what ("it was decided", "mistakes were made")
- Nominalisations: "perform an investigation" for "investigate", "make a decision" for "decide"
