# Memory: coding-round

This skill keeps its lessons log **outside the plugin**, at `~/.claude/skill-memory/coding-round.md`.
The installed plugin is a cached copy that is replaced on every update, and lessons are
personal, so they never belong in this repo. In the Claude app the file is not reachable; skip it.

The file is newest first, one to three lines per entry, written as a general rule.
Promote anything checkable to `evals.md`.
